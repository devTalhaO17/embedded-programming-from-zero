# 📖 Make: Electronics — Circuit Simulation Instructions

This directory contains pure Falstad circuit text files corresponding to hands-on experiments from ***Make: Electronics* by Charles Platt**.

---

## ⚡ How to Load Any Experiment in Falstad

1. Open the [Falstad Circuit Simulator](https://www.falstad.com/circuit/) in your browser.
2. In the top menu bar, click **`File`** $\rightarrow$ **`Import From Text...`** (or press `Ctrl + O` / `Cmd + O`).
3. Open any `.txt` file in this directory (e.g., `exp-02-battery-abuse.txt`).
4. Copy the entire file contents and paste them into the dialog box.
5. Click **`Import`** (or **`OK`**).
