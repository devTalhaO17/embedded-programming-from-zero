# Week 01: Electrical Foundations & Bitwise C Firmware ⚡

> **Module**: Month 01 — Foundations  
> **Duration**: 7 Days (2 hours/day)  
> **Target Outcome**: Master the physics of basic electrical circuits, fixed-width C data types, bitwise register manipulation, switch debouncing, and construct a 4-bit binary visualizer.

---

## 🗓️ Daily Schedule

| Day | Topic | Key Concepts | Lab / Simulation |
| :--- | :--- | :--- | :--- |
| **[Day 01](day-01/)** | Electrical Physics & Fixed-Width C Types | $V=IR$, Current, Resistance, Power ($P=VI$), `<stdint.h>` | Falstad DC Circuit Simulator |
| **[Day 02](day-02/)** | Circuit Topology & KVL/KCL | KVL, KCL, LED Forward Voltage ($V_f$), Resistor Sizing | Falstad 9V Dual-LED Circuit |
| **[Day 03](day-03/)** | C Memory Footprint & Alignment | `sizeof()`, Memory Limits, Data Alignment | GCC Host Test Program |
| **[Day 04](day-04/)** | Bitwise Operators & Register Masking | `&`, `\|`, `^`, `~`, `<<`, `>>`, `SET_BIT`, `CLEAR_BIT` | Wokwi Bare-Metal Register GPIO |
| **[Day 05](day-05/)** | Microcontroller Architecture & GPIO | DDR, PORT, PIN, Pull-Up Resistors, `volatile` | Wokwi Tactile Button + Internal Pull-Up |
| **[Day 06](day-06/)** | Mechanical Switch Debouncing | Contact Bounce Physics, Software Filter Algorithms | Wokwi Debounced Counter + Logic Analyzer |
| **[Day 07](day-07/)** | **Week 1 Capstone Project** | 4-Bit Binary Visualizer (0000–1111) with Register I/O | Wokwi 4-LED + Debounced Button Capstone |
